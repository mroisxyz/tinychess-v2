A general 4 KB Python chess engine built from scratch: 0x88 move generation, tapered piece-square evaluation, principal-variation search with a transposition table, quiescence, killers, history, null-move pruning and late-move reductions.

## Run it

```sh
python3 -P -s main.py
```
